# Portrait attribution

The 2019-20 Jamal Murray portrait is adapted from **“Jamal Murray 2020
(cropped)”** by All-Pro Reels, photographed January 4, 2020 and distributed via
Wikimedia Commons under [CC BY-SA 2.0](https://creativecommons.org/licenses/by-sa/2.0/).
The project copy was cropped to a circular transparent thumbnail for the chart.

- Source: https://commons.wikimedia.org/wiki/File:Jamal_Murray_2020_(cropped).jpg

The Kobe Bryant (2000-01), Shaquille O'Neal (2003-04), Manu Ginobili
(2004-05), Pau Gasol (2009-10), and Dwyane Wade (2010-11) portraits are
official NBA Player File headshots recovered from season-dated Internet
Archive snapshots. The remaining portraits use the NBA's season/team archive.

Every image's season status and source URL are recorded in
`headshot_manifest.csv`. If an exact-season NBA headshot cannot be recovered,
the downloader uses the closest available official NBA portrait and labels it
as a fallback rather than presenting it as season-specific.
